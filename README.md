# Ugent

Ugent (User Agent Platform) is a community source AI agent and workflow
automation platform built for community and personal automation needs.

The project focuses on helping people create AI agents, automated workflows, API
integrations, data processing pipelines, and visual flow-based task automation.

The current version is designed for personal projects, education, research,
evaluation, and non-commercial community use.
